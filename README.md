# ☕ Studyverse Café

A premium dark academia study café web app for Jaipur's night owls.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python + Flask
- Database: MySQL
- Email: Flask-Mail + Gmail SMTP

## Features
- Seat Reservation System
- Membership Plans
- Live Menu from Database
- Email Confirmations
- Contact Form

## Setup
1. pip install -r requirements.txt
2. cp .env.example .env
3. mysql -u root -p < database/schema.sql
4. python app.py
